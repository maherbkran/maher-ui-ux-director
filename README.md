# Maher UI/UX Director

A public Codex plugin marketplace containing the **Maher UI/UX Director** skill.

The skill audits, redesigns, implements, and verifies compact, distinctive, accessible product interfaces. It includes guidance for Arabic RTL, the UAE Design System, Phosphor iconography, strict Liquid Glass usage, UX writing, accessibility, performance, and visual QA.

## Install in Codex Desktop

Open **Plugins → Add → Add a marketplace** and enter:

- **Source:** `maherbkran/maher-ui-ux-director`
- **Git ref:** `main`
- **Sparse paths:** leave empty

Add the marketplace, open **Maher Design Tools**, and install **Maher UI/UX Director**.

Invoke it in a new Codex chat with:

```text
$maher-ui-ux-director
```

Example:

```text
Use $maher-ui-ux-director to audit this interface before changing code.
```
